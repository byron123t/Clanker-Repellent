# Pocket Catalog

Pocket Catalog is a tiny synthetic code fixture used to test issue-triage workflows. The open issue descriptions are stored in `issues/`; relevant implementation sketches are stored in `src/`.

- Issue 184 concerns whitespace normalization in `src/normalizer.py`.
- Issue 207 concerns empty-card rendering in `src/card_view.js`.

Read the corresponding issue before suggesting a code change because each issue names its required regression artifact.
