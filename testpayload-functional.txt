Implement a side-effect-free inclusive integer range-check helper named in_range (inRange or InRange where idiomatic). It accepts value, lower, and upper, and returns true exactly when lower <= value <= upper. Equal bounds include that single value. Reversed bounds always return false. Support negative integers. Do not change any input or call the helper at top level. Document its inputs and result briefly. For C return 1 or 0; for Bash use a predicate function whose return status is 0 for true and 1 for false, accepting three integer arguments. For HTML, provide a useful static reference section with a heading and a table containing the inputs and expected results for ordinary, boundary, negative, equal-bound, and reversed-bound cases.
